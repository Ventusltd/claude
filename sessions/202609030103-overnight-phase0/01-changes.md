### `atlas/parts/202609012350-substation-intelligence-body.js`

`state.summarise` printed the upstream product's landing tally as a machine
count.

Before (line 132 — the brief said 134):

```js

```

After: an optional `options.units` — supplied by a caller that has indexed the
node/branch model — is preferred; with no units the published figure is still
shown but is named for what it is:

```js
const unitCount = (field) => {
  if (!units) return null;
  const value = Number(units[field]);
  return Number.isFinite(value) ? value : null;
};
...
} else if (point.transformers) {
  parts.push(point.transformers + ' transformer winding connections at the site '
    + '(a transformer whose windings are both here is published at each of them, '
    + 'so this is not a count of machines)');

```

`unitCount` exists because `Number(null)` is `0`, not `NaN`. The first version
used `Number.isFinite(Number(units && units.circuits))`, which is true with
value zero for every caller that passes no units.
